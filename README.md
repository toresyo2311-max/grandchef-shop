# 그랑쉐프몰 (GRANDCHEF MALL) — 1차 시안

(주)그랑쉐프 자체 주문·결제 판매몰의 **1차 시안(demo)** 입니다.
정적 호스팅(GitHub Pages)에서 동작하는 상품 카탈로그 + 장바구니 + 주문서 흐름을 구현했습니다.

- 라이브: https://toresyo2311-max.github.io/grandchef-shop/
- 회사소개 홈페이지: https://grandchef.co.kr

## 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 셸(상단 고지바·헤더·푸터) + 라우팅 컨테이너 |
| `assets/styles.css` | 디자인 시스템(웜 크림 #F7F3EC · 차콜 · 브론즈) |
| `assets/data.js` | 상품 20종(업소용 10 · 가정용 10)과 회사·배송 정보 |
| `assets/app.js` | 해시 라우터, 카탈로그·상세·장바구니·주문서·주문내역 로직 |
| `assets/products/*` | 회사소개 홈페이지의 오리지널 제품 이미지 재사용 |

## 동작 범위

- 상품 탐색: 카테고리 필터 · 정렬 · 검색
- 상품 상세: 규격 옵션별 금액, 수량, `회원/견적 협의` 옵션은 견적 요청으로 전환
- 장바구니: 수량·삭제·합계 자동 계산, `localStorage` 유지
- 주문서: 주문자/배송지, 부울경 직배송·택배, 신용카드·간편결제·무통장입금(세금계산서)
- 결제 버튼: **PG(토스페이먼츠/포트원) 실결제 연동 대기** 모달 + 주문번호·요약, 실제 청구 없음
- 주문내역서: 저장·재조회·인쇄(`window.print`)

## 주의

- 표시 금액은 실제 판매가가 아닌 **시안 예시가**입니다.
- 결제(PG)는 연동되지 않았습니다. 주문서는 브라우저 `localStorage`에만 저장되며 서버로 전송되지 않습니다.
- 상품 이미지는 회사소개 홈페이지의 예시 이미지를 재사용했습니다.
